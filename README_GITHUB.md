# KAFV 수산물 가격정보 AI v0.4

## 이번 수정 핵심
- 코드 직접입력 제거
- 품목명 / 품종·상태 / 등급 / 시군구 / 시장을 이름 목록에서 선택
- PC: 선택란 마우스오버 또는 클릭으로 목록 표시
- 모바일: 탭 후 스크롤 선택
- 선택목록에 이름과 코드를 함께 표시하되, 사용자는 이름 중심으로 선택
- 하위 화면의 X는 전 단계 메뉴로 복귀
- 상위 메뉴의 X는 채팅화면으로 복귀
- `Failed to fetch`를 Cloudflare CORS 안내 메시지로 변경
- 기간조회 시작일 기본값 추가
- 추세·등락은 최근가격의 최신 기준일을 찾아 조회
- 이미지 파일명을 의미 있는 이름으로 통일
